# 用知识库思路分析问题

当用户说「用人生指南…」「用毛选…」或同时点名两者来分析某个具体问题时，按下面做。

## 1. 选定知识库

| 用户说法 | 打开 |
| --- | --- |
| 人生指南 / 高性价比人生指南 / HowToLiveBetter | `.cursor/skills/life-decision-guide/SKILL.md` + `knowledge/how-to-live-better/` |
| 毛选 / 毛泽东选集 | `.cursor/skills/mao-anthology/SKILL.md` + `knowledge/mao-zedong-anthology/` |
| 两个都提 | 两边都查，分节回答后再综合 |

## 2. 必须先检索再答

- **人生指南**：Grep `book/`，条目整条读完；按成本、收益口径、证据等级写；注明第几节第几条。≥7 天未同步则先 `sync.sh`。
- **毛选**：Grep `volumes/`，读相关篇；用敌我友 / 主要矛盾 / 实际出发 / 组织落地等框架；注明卷次篇名。不自动同步。

查不到就说查不到，常识单独标明，不冒充库内结论。

## 3. 固定输出骨架

1. **一句话结论**
2. **解决思路**（分步，可执行）
3. **原因 / 依据**（链回知识库出处）
4. **边界**（书没写的、需要专业人士的、历史结论与当下应用的区分）
