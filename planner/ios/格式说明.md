# 日次入库格式（给快捷指令用）

你已建好提醒事项列表：**生活**、**工作**（名称不要改）。

我每次整理后给你一段纯文本：**一行一条**，用竖线 `|` 分隔。你复制后运行快捷指令「日次入库」。

## 一行长什么样

```text
列表|标题|提醒时间|备注
```

| 段 | 必填 | 说明 |
| --- | --- | --- |
| 列表 | 是 | 只能是 `生活` 或 `工作` |
| 标题 | 是 | 事项内容 |
| 提醒时间 | 否 | `YYYY-MM-DD HH:mm`（24 小时制，北京时间）。留空 = 不设提醒 |
| 备注 | 否 | 可留空 |

## 示例（可直接拿去试跑）

```text
生活|试用：日次入库（可删）|2026-09-29 09:00|跑通后删掉
工作|试用：工作列表（可删）|2026-09-29 18:00|跑通后删掉
生活|周末买菜|2026-10-04 10:00|记得带袋子
工作|交方案|2026-10-07 15:00|
```

只有日期、没有钟点时，我会写成当天 `09:00`。  
纯待办、不需要响铃时，提醒时间那段留空，例如：

```text
生活|有空时整理阳台||不急
```

## 日历与节假日

- 带提醒时间的事项会出现在「提醒事项 → 今天 / 计划」。
- 想在「日历」App 里一起看：打开日历 → 底部「日历」→ 勾选与提醒事项相关的项（不同 iOS 文案略有差别）。
- 中国节假日：手机 **设置 → 日历 → 替代日历 → 中国大陆节假日**。
