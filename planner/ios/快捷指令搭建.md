# 快捷指令「日次入库」搭建（只需一次）

用 iPhone 自带 **快捷指令** App，按顺序做完即可。大约 3 分钟。

你的列表名必须是：**生活**、**工作**。

---

## 1. 新建

1. 打开 **快捷指令** → 右上角 **+**
2. 点顶部名称，改成：`日次入库`
3. 右上角 **ⓘ**（或下拉）→ 打开 **显示在分享表中** → 勾选 **文本**

---

## 2. 添加操作（严格按顺序）

每个操作都在底部搜索框搜中文名添加。

### ① 拿到要导入的文本

1. 搜索添加：**询问**  
   - 提示：`粘贴日次清单`  
   - 输入类型：**文本**  
   - 若有「默认答案 / 剪贴板」，选 **剪贴板**（这样你先复制我发的内容，打开快捷指令会自动带上）

### ② 拆成多行

2. 添加：**分割文本**  
   - 输入：询问结果  
   - 分隔符：自定义 → 输入一个换行（点分隔符，选「换行」）

3. 添加：**对每个重复**  
   - 重复：分割后的文本

### ③ 在「重复」里面：拆每一行并写入提醒

以下都加在 **「对每个重复」的蓝色块内部**：

4. 添加：**分割文本**  
   - 输入：**重复项目**  
   - 分隔符：自定义 → 输入英文竖线 `|`（不要两边空格）

5. 添加：**获取列表中的项目**  
   - 列表：上一步分割结果  
   - 获取：**索引**的项目 → `1`  
   - 把这个变量重命名为 `列表名`（点变量 → 重命名）

6. 再添加一个：**获取列表中的项目** → 索引 `2` → 重命名为 `标题`

7. 再添加：**获取列表中的项目** → 索引 `3` → 重命名为 `提醒时间`  
   - 若「没有项目」可能报错：可在此步打开「错误时继续」类选项（若有），或保证我给你的行始终有 3 个 `|` 段（空也保留 `|`）

8. 再添加：**获取列表中的项目** → 索引 `4` → 重命名为 `备注`  
   - 同样建议错误时继续，没有备注就当空

9. 添加：**如果**  
   - 条件：`列表名` **是** `工作`

10. 在「如果」为真的分支里添加：**添加提醒事项**  
    - 名称：`标题`  
    - 列表：固定选 **工作**  
    - 提醒：若 `提醒时间` 有值 → 打开提醒，日期用「从提醒时间获取日期」  
    - 备注：`备注`

11. 在「否则」分支里再添加：**添加提醒事项**  
    - 同上，列表固定选 **生活**

#### 提醒时间怎么接到「添加提醒事项」

在「添加提醒事项」之前（两个分支里各做一次，或提到如果之前共用）：

- 添加：**如果** → `提醒时间` **有值**（或「其长度大于 0」）  
- 为真时：添加 **日期** / **从文本获取日期**（把 `提醒时间` 交给它）→ 在「添加提醒事项」里把「提醒」打开并选这个日期变量  
- 为假时：添加提醒事项但不打开「提醒」

不同 iOS 版本操作名可能是：

- `日期`
- `从输入中获取日期`
- `调整日期`

只要能把 `2026-10-07 15:00` 变成日期变量即可。

### ④ 结束

12. 在「对每个重复」**外面**最后添加：**显示通知**  
    - 正文：`日次已入库`

---

## 3. 放到手指边上

快捷指令 **ⓘ** → **添加到主屏幕**（推荐）。

---

## 4. 试跑

1. 复制下面 2 行（或打开 [`示例-日次入库.txt`](./示例-日次入库.txt) 全选复制）：

```text
生活|试用：日次入库（可删）|2026-09-29 09:00|跑通后删掉
工作|试用：工作列表（可删）|2026-09-29 18:00|跑通后删掉
```

2. 点主屏幕 **日次入库** → 粘贴 → 运行  
3. 打开 **提醒事项**，在「生活」「工作」里应各有一条试用  
4. 删掉试用两条  

若失败：把快捷指令里报错的那一步截图发我，我按你的 iOS 版本改步骤。

---

## 5. 日常协作（你和我）

| 你 | 我 |
| --- | --- |
| 口语说事项、改期、做完了 | 分类到生活/工作，写好入库文本 |
| 复制我给的文本，跑「日次入库」 | 长期帮你维护这份清单 |

直接发我就行，例如：

> 下周三下午 3 点交方案，周末买菜，明天早上 9 点提醒交社保
