# 日次清单

表头**横向**，每条记录**纵向**一行。

## 文件

| 文件 | 作用 |
| --- | --- |
| [`清单.json`](./清单.json) | 唯一数据源（含顶部 `rules` + `items`） |
| [`清单看板.html`](./清单看板.html) | 零外链看板：规则设定 + 表格 + 拖拽 |

## 表格规则设定（全局，不在每一行）

写在 `清单.json` 的 `rules`：

| 规则 | 说明 | 当前默认 |
| --- | --- | --- |
| `spanThresholdDays` | 跨度超过多少天，才启用 Cursor 复提醒 | 7 |
| `cursorRemindIntervalDays` | 满足跨度后，每多少天在 Cursor 提醒一次 | 7 |
| `sortMode` | `seq` 按序号 · `priority` 按优先级（高→中→低） | `seq` |

按序号时可拖动排序并自动改序号；按优先级时仅按优先级显示，不可拖动。

## 行字段

序号 · 清单项目 · 子项目 · 优先级 · 完成日期 · 提醒日期 · 提醒时间 · 手机日历提醒 · 完成

手机日历提醒默认 **否**。

## 在 Cursor 里协作

直接说加减改查、改规则、调顺序，例如「看清单」「排序改成按优先级」「跨度改成 5 天」。
