# 日次清单

表头**横向**，每条记录**纵向**一行；可拖动排序，序号按位置自动更新。

## 文件

| 文件 | 作用 |
| --- | --- |
| [`清单.json`](./清单.json) | 唯一数据源（Cursor 对话里主要由我维护） |
| [`清单看板.html`](./清单看板.html) | 零外链表格看板：查看 / 编辑 / 拖拽排序 |

## 列

序号 · 清单项目 · 子项目 · 优先级 · 完成日期 · 提醒日期 · 提醒时间 · 手机日历提醒 · 跨度超过(天) · Cursor复提醒间隔(天)

## 在 Cursor 里协作（主路径）

直接说加减改查、改期、调顺序，例如：

- 「看清单」
- 「第 1 条已完成」
- 「把打球挪到第 2」

我会改 `清单.json`。

## 打开看板（可选）

在 `planner` 目录执行：

```bash
python3 -m http.server 5173
```

浏览器打开：`http://localhost:5173/清单看板.html`

改完点「导出 JSON」，用导出的文件覆盖仓库里的 `清单.json`（或把内容发给我同步）。

## 手机日历提醒

默认 **否**。仅当某条显式为「是」时，可以说「给这条生成日历文件」，我再给你 `.ics`。

## 长周期 Cursor 提醒

若「今天 → 完成日期」天数 ≥「跨度超过(天)」，且填写了「Cursor复提醒间隔(天)」，我会按间隔在对话里提醒你。
