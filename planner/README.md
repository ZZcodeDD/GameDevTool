# 日次 · iPhone 提醒事项协作

只用苹果手机系统「提醒事项」+「日历」，不依赖网页、不依赖 VPN、不要求电脑开机。

## 准备一次

1. 提醒事项列表：`生活`、`工作`
2. 按 [`ios/快捷指令搭建.md`](ios/快捷指令搭建.md) 搭建快捷指令「日次入库」
3. （建议）设置 → 日历 → 替代日历 → 打开「中国大陆节假日」

## 每天怎么用

1. 在对话里用自然语言告诉我事项
2. 我回复一段「一行一条」入库文本
3. 复制 → 运行「日次入库」→ 写入对应列表并设好提醒

- 格式：[`ios/格式说明.md`](ios/格式说明.md)
- 试跑：[`ios/示例-日次入库.txt`](ios/示例-日次入库.txt)
